# 📊 Vrinda Store Data Analysis Dashboard

## 📌 Project Overview
This project contains a sales analysis dashboard created using Microsoft Excel to analyze Vrinda Store's sales data.

## 🛠️ Tools Used
- Microsoft Excel
- Data Analysis
- Charts and Data Visualization

## 🎯 Project Objectives
- Analyze sales performance.
- Identify important sales trends.
- Present data through visualizations.
- Generate meaningful business insights.

## 📂 Project File
- Vrinda Store Data Analysis.xlsx

## 🚀 How to Use
1. Download the Excel file from this repository.
2. Open it in Microsoft Excel.
3. Explore the dashboard and its charts.
